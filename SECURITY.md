# Security and limitations

Private local-first release candidate. Use trusted JSON files; do not expose as an unauthenticated endpoint. CLI rejects duplicate keys, nonfinite numbers and files above 32 MiB. The auditor enforces evidence/decision/reference/depth/visit limits and strict timestamp grammar. No external network calls, arbitrary code execution or real actions. Hashes prove consistency relative to retained inputs/receipts, not source authenticity or historical existence; caller-supplied timestamps can be false. Python JSON canonicalization is not a cross-language standard. Do not include secrets or sensitive personal data in bundles. Report vulnerabilities privately to the project owner until a public contact is established.
