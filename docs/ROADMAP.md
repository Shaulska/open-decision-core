# Roadmap and release gates

1. Preview (implemented): JSON contract, exact evidence replay, temporal audit, basic split audit, CLI, deterministic receipts, offline tests, static report; v0.2 includes a curated six-release BEA benchmark and interactive replay; v0.3 hardens input/time semantics, bounds lineage traversal, and adds clean-install packaging checks.
2. Initial open-source MVP: Apache-2.0 approved; release checks and publication steps in LAUNCH_CHECKLIST.md. Independent testing and expanded external datasets remain future work.
3. Future: append-only evidence/outcome registry, adapters, robust fold validation, signed checkpoints and interactive dashboard.
4. Policy module: risk/coverage, abstention and human review; independent labels, calibration, future holdout. No live actuation in preview.
5. Research Lab: reproducible comparison of predictions and policies, calibration, uncertainty and drift. No claims of demonstrated model benefit yet.

Public release and application should follow measured results, real use and owner approval; acceptance into any grant program is not guaranteed.
