Official form: https://openai.com/form/codex-for-oss/ · terms: https://learn.chatgpt.com/docs/codex-for-oss-terms

Prerequisites: owner-approved public repository and public GitHub profile; accurate maintainer role and identity; ChatGPT account email; OpenAI organization ID. Active maintenance and ecosystem importance/usage are assessed. No guaranteed selection or entitlement. No confidential information, no invented adoption metrics.

## Why does this repository qualify? (draft under 500 characters)

Open Decision Core is an early-stage toolkit for checking whether evidence used by AI and ML decisions was available at the declared cutoff. Its local Python MVP audits exact data versions, lineage and split manifests, with reproducible receipts and a real BEA GDP-revision demo. We aim to make temporal integrity checks easy to integrate into research and agent evaluation. Adoption is not yet established.

## How will you use API credits? (draft under 500 characters)

We would use Codex and API credits to review contributions, generate adversarial regression tests, automate release checks, document integrations and build reproducible benchmark adapters. We plan to extend the shared evidence contract into selective decision evaluation and a research lab, while retaining deterministic, offline audit checks. Credits would support this OSS repository only.

## Anything else (draft under 500 characters)

The MVP is deliberately small and local-first: no mandatory API, GPU or hosted service. It distinguishes declared provider publication time from actual local receipt and refuses to silently accept missing evidence. The initial benchmark has 24 designed scenarios based on six real releases; it is not an independent accuracy estimate. Further external feedback and validation are planned.
