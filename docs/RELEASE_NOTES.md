# v0.3.0 — first open-source MVP

Experimental release of Temporal Audit, the first layer of Open Decision Core.

- Python SDK and CLI: exact-version replay, declared availability, lineage, split audit and deterministic receipts.
- Three verdicts: PASS, BLOCK and UNVERIFIED.
- Six official BEA GDP releases, 24 designed replay scenarios, all matching their expected verdicts (not independent accuracy estimates).
- Static offline interactive replay and reproducible project website.
- Apache-2.0 for project code and original documentation.

Decision Policy and Research Lab are planned. No source authentication, production security certification, predictive validation or established adoption is claimed. No runtime dependencies or mandatory external API.
